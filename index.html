Konfigurasi Koneksi Google Sheet

Hubungkan aplikasi dengan Google Sheets Anda melalui Apps Script Web App URL.

Langkah-Langkah Pengaturan:

  1. Buat Google Spreadsheet baru di Google Drive Anda.
  2. Buka spreadsheet tersebut, lalu masuk ke menu Extensions (Ekstensi) > Apps Script.
  3. Hapus semua kode bawaan, lalu salin dan tempel isi file google_script.js dari folder proyek ini ke editor Apps Script.
  4. Klik tombol Save (Simpan) (ikon disket).
  5. Klik tombol Deploy > New deployment di bagian kanan atas editor.
  6. Pilih type: Web app. Setel opsi berikut:
    • Execute as: Me (Email Anda)
    • Who has access: Anyone
  7. Klik Deploy. Berikan izin akses Google jika diminta.
  8. Salin Web App URL yang dihasilkan (berawalan https://script.google.com/macros/s/...).
  9. Tempel URL tersebut di form bawah ini dan klik Hubungkan.
